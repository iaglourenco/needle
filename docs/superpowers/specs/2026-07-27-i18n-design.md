# Internacionalização (i18n) — Needle

**Data:** 2026-07-27
**Status:** Aprovado

## Objetivo

Permitir que o usuário escolha o idioma da aplicação (PT-BR ou EN) em
Configurações. Cobre tanto a UI Vue (janela principal) quanto as strings
geradas pelo lado Rust (menu da bandeja, tooltip, notificações do SO), já
que hoje ambas estão hardcoded em português.

## Escopo

- Idiomas: `pt-BR` (padrão/atual) e `en`.
- UI Vue completa: nav (`App.vue`), lista de sessões (`SessionList.vue`,
  `SessionItem.vue`, incluindo labels de estado como "Running"/"Aguardando
  input"), tela de configurações (`SettingsView.vue`).
- Backend Rust: itens do menu da bandeja, tooltip da bandeja, notificações
  do SO (`main.rs`, `tray.rs`).
- Fora de escopo: strings de log/erro internas (`eprintln!`, comentários de
  código) — não são visíveis ao usuário final.

## Arquitetura

Uma única fonte de verdade: campo `language` (`"pt-BR" | "en"`) dentro do
`Settings` já persistido em `settings.json`, roteado pelos comandos Tauri
`get_settings`/`save_settings` já existentes. Duas camadas de tradução
consomem esse mesmo valor:

- **Frontend**: `vue-i18n`, locale reativo, controla toda a UI Vue.
- **Backend Rust**: módulo `i18n.rs` próprio (dicionário simples via
  `match`, sem dependência de crate de i18n) — cobre bandeja/notificações,
  que o Vue não alcança (rodam mesmo com a janela fechada).

## Componentes

### Rust

- `settings.rs`: novo enum
  ```rust
  #[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
  pub enum Language {
      #[serde(rename = "pt-BR")]
      PtBr,
      #[serde(rename = "en")]
      En,
  }
  ```
  com `Default` = `PtBr`. Campo `language: Language` adicionado a
  `Settings` com `#[serde(default)]` — `settings.json` antigo sem a chave
  continua carregando (default `pt-BR`, comportamento atual preservado).
  `Settings` continua `Copy` (enum sem dados também é `Copy`).

- `i18n.rs` (novo módulo): funções puras parametrizadas por `Language`
  substituindo as strings hoje hardcoded:
  - `menu_label(lang, id: MenuId) -> &'static str` — "Abrir Needle",
    "Configurações", "Reconfigurar hooks", "Sair" e equivalentes em inglês.
  - `tray_tooltip(lang, state: Option<SessionState>) -> String` — as 6
    variantes hoje em `tooltip_for`.
  - `notif_title(lang, state: SessionState) -> &'static str` — as 4
    variantes hoje em `notify_if_needed`.
  - Strings de notificação de auto-config/reconfigure em `main.rs`
    ("Needle configurado", "Hooks do Claude Code registrados
    automaticamente.", "Hooks reconfigurados.").

- `AppState` (main.rs) ganha um campo com os handles dos 4 `MenuItem` da
  bandeja (open/settings/reconfigure/quit), guardados no `setup()` depois
  de criados, para permitir re-rotulagem em runtime sem reiniciar o app.

- `save_settings`: após persistir e atualizar `state.settings`, se
  `new_settings.language` mudou em relação ao valor anterior:
  - chama `.set_text(i18n::menu_label(...))` nos 4 itens do menu;
  - chama `tray::refresh_from_db(&state)` (recalcula o tooltip já
    lendo o novo idioma do `AppState.settings`).

- `tray.rs`: `tooltip_for` e `notify_if_needed` passam a receber
  `lang: Language` (lido de `app_state.settings.lock().unwrap().language`
  no ponto de chamada) em vez de retornar string fixa.

### Frontend (Vue)

- Nova dependência `vue-i18n` (`^10`).
- `src/i18n/index.ts`: cria instância `createI18n` (Composition API,
  `legacy: false`, `fallbackLocale: 'pt-BR'`), importando os JSONs de
  mensagens.
- `src/locales/pt-BR.json` e `src/locales/en.json`: chaves extraídas de
  toda string hardcoded hoje presente em `App.vue`, `SessionList.vue`,
  `SessionItem.vue` (inclui mapa de labels de estado —
  `Running`/`WaitingInput`/`NeedsAttention`/`Idle`/`Error`/`Stale`/`Ended`)
  e `SettingsView.vue`.
- `src/lib/types.ts`: `Settings` ganha `language: "pt-BR" | "en"`.
- `main.ts`: passa a ser assíncrono — busca `api.getSettings()` antes de
  montar a árvore Vue, seta o locale inicial (`i18n.global.locale.value =
  settings.language`), só então `createApp(App).use(pinia).use(i18n).mount(...)`.
  Evita flash de idioma errado no primeiro render.
- `SettingsView.vue`: novo `<select>` de idioma na seção "Geral", ao lado
  do checkbox de autostart. Ao trocar, aplica preview instantâneo
  (`locale.value = ...`) mas só persiste no disco ao clicar
  "Salvar"/"Save" — mesmo comportamento já existente para os outros
  campos do formulário (nada é salvo sozinho sem o clique).

## Fluxo de dados

1. Start: Rust carrega `settings.json` → `language` → constrói bandeja com
   labels já traduzidos. Frontend `main.ts` busca settings → seta locale
   do `vue-i18n` → monta app.
2. Usuário troca idioma no `<select>` de Configurações → preview
   instantâneo na UI Vue → clica Salvar → `save_settings` (Tauri command)
   persiste, Rust re-rotula menu da bandeja e recalcula tooltip. Nenhum
   restart necessário em nenhum dos dois lados.

## Erros / Compatibilidade

`settings.json` de instalações existentes não tem a chave `language`;
`#[serde(default)]` cobre isso carregando `pt-BR` — sem migração, sem
quebra.
